# Trafaret Line — інтернет-магазин трафаретів (trafaret-line.com.ua)

Магазин трафаретів, заготовок з акрилу та ПЕТ і вивісок для України: каталог (667 товарів, 56 розділів), конструктори «Свій напис», «Цілим словом», «Вільне полотно» і вивісок з превʼю та ціною одразу, оформлення з Новою поштою, WayForPay, рахунком для ФОП/ТОВ і чеками Вчасно.Каси. Власник: Денис. Документи проєкту ведуться російською, інтерфейс сайту українською.

## Склад репозиторію

| Папка | Що це |
| --- | --- |
| `web/` | Вітрина: Next.js 15 (App Router) + TypeScript + Tailwind 4. Порт 3100. |
| `backend/` | Магазин: Medusa 2.18 (товари, ціни, замовлення, адмінка `/app`, «Простий кабінет»). Порт 9000. |
| `bot/` | Telegram-бот для додавання товарів фото + підписом. |
| `catalog/data/` | Дані каталогу для імпорту в Medusa (фото зберігаються окремо, не в репозиторії). |
| `docs/` | ТЗ (`docs/tz/TZ.md`), дослідження, дизайн, звіти QA. |
| `CLAUDE.md` | Правила проєкту і коду. |

Правило коду: тільки повний робочий код, логіка в `web/lib` і `web/services`, типи в `web/types`. Формули цін і геометрії мають копії в `backend/src/shared` (мають збігатися з `web/`).

## Запуск локально

Потрібні Node.js 22 і PostgreSQL 16.

```bash
# 1. Налаштування: скопіюйте приклади і впишіть свої значення
cp web/.env.example web/.env.local
cp backend/.env.template backend/.env
cp bot/.env.example bot/.env

# 2. Магазин (Medusa)
cd backend
npm install --legacy-peer-deps
npx medusa db:migrate
npm run seed                 # регіон «Україна», канал продажу, матеріали
npx medusa develop           # http://localhost:9000, адмінка /app

# 3. Вітрина
cd ../web
npm install
npm run build && npm start   # http://localhost:3100

# 4. Імпорт каталогу (Medusa зупинена): див. docs/RUN.md
```

На ноутбуці власника все запускається файлом «Запустити сайт.bat» (портативний Node у `.tools/`, база в `D:\tl-dev`).

Перевірка коду: `npx tsc --noEmit -p web`, `npx tsc --noEmit -p backend`, `cd bot && npm test`.

## Ключі та секрети

Паролі, ключі API і доступи до сервера в репозиторій не потрапляють: тільки у файли `.env` (вони в `.gitignore`). Перелік потрібних змінних із описом є в `web/.env.example`, `backend/.env.template`, `bot/.env.example` і в `docs/RUN.md`.

## Хостинг

Сервер власника під керуванням FastPanel (nginx + Node.js + PostgreSQL), домен trafaret-line.com.ua. Розгортання на сервер робиться тільки з окремого дозволу власника; доступи до сервера в репозиторії не зберігаються.
