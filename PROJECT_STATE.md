## Шаг 0.5. Единые типы и CI — ✅

| Тип из промта | Файл | Что в нём |
| --- | --- | --- |
| product | `web/types/product.ts` | Формат `materials.json` (`MaterialFacts`, `MaterialsKnowledge`) и все типы каталога и материалов |
| order | `web/types/order.ts` | Строки заказа, контакт, доставка, оплата, ответ оформления |
| vector | `web/types/vector.ts` | Слои станка, линии, отверстия, деталь для SVG/DXF (перенесено из `lib/export/layers.ts`) и геометрия |
| fop | `web/types/fop.ts` | Формат `rules_fop.json`, реквизиты продавца для счёта |
| shipping | `web/types/shipping.ts` | Формат `rules_logistics.json`, посылка, типы Новой Почты |
| system | `web/types/system.ts` | Форматы моков API, ошибки API сайта, где читаются переменные окружения |

Все типы доступны из `web/types/index.ts`. Новые файлы добавляют новые типы или собирают имеющиеся в одном месте; старые типы не копируются.

CI: `.github/workflows/ci.yml` на каждый PR и push в main. Проверяет:
- типы;
- линтер;
- юнит-тесты (36);
- сборку сайта;
- сквозные тесты (10);
- backend (типы, сборка, тест на PostgreSQL);
- дублирование кода (порог 1,5 %).
