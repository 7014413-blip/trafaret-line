# Telegram-бот Trafaret Line: товары с телефона

Вы присылаете боту фото и подпись → бот уточняет кнопками недостающее → заявка уходит в общую очередь конвейера товаров → конвейер делает фото в стиле сайта, мокапы, тексты, SEO и черновик в адмінке → бот присылает кнопку «Опублікувати на сайті».

Бот только принимает заявки и публикует готовые черновики. Всю обработку делает конвейер (ветка «Автоконвейер товаров по референсам», план `research/avto-konveier-tovariv.md`). Формат очереди задаёт конвейер.

## Установка (один раз)

1. Скопируйте папку `telegram-bot` в `D:\сайт клод\сайт украина\bot` (рядом с `web`).
2. В Telegram: @BotFather → `/newbot` → имя и username → он выдаст токен.
3. В папке `bot` скопируйте `.env.example` в `.env` и впишите `TELEGRAM_BOT_TOKEN=...`. **Токен никуда не отправляйте.**
4. Запустите `Запустити бота.bat`. Первый раз он установит зависимости (1–2 минуты).
5. Напишите боту `/start`: он покажет ваш Telegram ID. Впишите его в `.env` в `ALLOWED_TELEGRAM_IDS=` и перезапустите бота (закрыть окно, снова `Запустити бота.bat`).
6. Для кнопки публикации: адмінка Medusa → Settings → Secret API Keys → Create, ключ впишите в `MEDUSA_ADMIN_API_KEY=`. Без ключа всё работает, кроме этой кнопки (публикуете в адмінке сами).

Бот работает, пока открыто его окно и включён ноутбук. Нагрузка минимальная: один процесс Node.js без обработки изображений.

## Как пользоваться

- Фото (можно альбомом) + подпись: `тірамісу Ø34 PET 350 грн`, `сніжинка 15, 20, 25 см, пластик, 120 грн`, `напис на торт «З днем народження» 20 см`.
- Макет SVG/DXF/PDF/AI/EPS/CDR — отправьте файлом.
- Бот понимает: цену (`грн`, `₴`, `ціна 350`), размеры (`15 см`, `30x20 см`, `Ø34`, несколько через запятую), материал (PET/пластик, полистирол белый/чёрный, акрил с толщиной и цветом, зеркальный), тип (заготовка, на заказ, готовый) и категорию по ключевым словам.
- Чего не хватает — кнопки на карточке: Категорія, Тип, Матеріал, Розмір, Ціна, Назва.
- Обязательно: фото или макет, категория, тип. Остальное конвейер подберёт по правилам каталога.
- Поставщика в подписях не упоминайте.
- Команды: `/status` — состояние заявок, `/card` — текущая карточка, `/cancel` — отменить, `/id` — ваш ID.

## Куда пишет

`D:\сайт клод\сайт украина\factory\inbox\<id>\`:
- `intake.json` — заявка по схеме конвейера (`source: telegram`, `priority: now`);
- `photos\01.jpg…`, `layout\…` — ваши файлы;
- `status.json` — бот создаёт со статусом `new`, дальше его меняет только конвейер.

Пока заявка собирается, файлы лежат в `factory\inbox\.staging\` (конвейер эту папку не читает); при отправке папка целиком переименовывается в `<id>`, поэтому конвейер никогда не видит недописанную заявку.

Бот раз в минуту читает `status.json` своих заявок и пишет вам при каждом изменении. На статусе `draft` с `medusa_handle` появляется кнопка «Опублікувати на сайті»: бот переводит товар в Medusa из черновика в опубликованные и больше ничего в нём не меняет.

## Для разработки

```
npm install
npm test        # сборка + тесты (разбор подписи, очередь, состояние)
npm run build
npm start
```

Структура: `src/index.ts` — запуск; `src/handlers/` — команды, фото/файлы, текст, кнопки, доступ; `src/lib/` — по файлу на функцию (разбор подписи, черновик, очередь, Medusa, файлы Telegram, карточка, наблюдатель статусов, состояние); `src/types/` — все типы. `data/` — снимок категорий и материалов каталога для кнопок (обновлять при изменении `catalog/data/categories.json` или `materials.json`, либо задать `CATALOG_DIR` на папку каталога).

Переезд на сервер (только с отдельного «да» Дениса): тот же код, `INBOX_DIR` на серверную очередь, запуск как службы. Позже очередь станет таблицей `factory_jobs` в Postgres — меняется только `src/lib/inbox.ts`.
