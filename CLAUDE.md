# Сайт трафаретов для Украины — правила проекта

Интернет-магазин **Trafaret Line** (trafaret-line.com.ua): трафареты, заготовки из акрила и ПЕТ, многослойные вывески. Владелец — Денис. Документы проекта ведём по-русски, интерфейс сайта — украинский (основной), русский, английский.

## Границы
- Работаем только в этой папке (`D:\сайт клод\сайт украина`). Папку `D:\CRM Topperok` (CRM «Топерок») не трогаем: это отдельный проект.
- Node.js портативный: `.tools\node` (22 LTS, установлен с согласия Дениса 08.10.2026). В системе ничего не ставим и не меняем. Перед запуском команд: `$env:Path = "D:\сайт клод\сайт украина\.tools\node;" + $env:Path`. npm-кэш: `.tools\npm-cache`.
- Новые программы вне папки, изменения в системе, сервер — только с явного «да» Дениса. Зависимости npm — только локально в `web/`.
- Сервер управляется через FastPanel (доступ у Дениса). Логины, пароли и ключи в файлы проекта не записываем. На сервер не заходим без отдельного «да». Ничего не публикуем и не деплоим без его слова.

## Где код
- `web/` — Next.js 15 + TypeScript + Tailwind 4 (App Router). Запуск: `npm run dev` или `npm run build && npm start`, порт **3100** (не пересекается с CRM). Проверка: `npm run typecheck`, `npx next build`.
- **Правило кода (Денис, 09.10.2026):** только полный рабочий код, без заглушек, `// TODO`, «набросков» и сжатых функций. Каждая логическая функция в своём файле в `web/lib` или `web/services`, все типы в `web/types` (вход `types/index.ts`). Next.js App Router (у нас 15, структура как в 14).
- Структура `web/`: `types/` (материалы, холст, упаковка, вес, заказ, счёт B2B, интеграции); `lib/materials.ts`; `lib/calculators/` (geometry — площадь и периметр, weight — вес по плотности, pricing — цена, packaging — тубус или коробка, signage — вывески, cut-metrics, design-check); `lib/geometry/` (Clipper2: bridges — мостики, weld — сварка букв, thin-zones, canvas-analysis, shapes); `lib/text/` (шрифты и раскладка); `lib/export/layers.ts` (SVG и DXF для станка); `services/` (Нова Пошта, Вчасно.Каса, Gemini, Opendatabot); `app/api/` (роуты этих сервисов).
- Формулы цены: `web/lib/calculators/pricing.ts` и `signage.ts`, копии в `backend/src/shared/lib/calculators` должны совпадать (вместе с `lib/materials.ts`, `lib/calculators/geometry.ts`, `types/`).
- Контент главной: `web/data/home.ts`, картинки `web/public/demo/`.

## Ключевые решения (подробно — ТЗ раздел 0)
- **Технологии:** Next.js + TypeScript (витрина), Medusa v2 (магазин), Payload CMS (страницы, блоки, тема из админки), Meilisearch, PostgreSQL.
- **Отдельный ресурс.** topperok.com.ua работает дальше, его трафареты входят в новый каталог.
- **Связь с CRM Топерок** через API и вебхуки; CRM — главная по заказам и клиентам.
- **Филиалы отправки:** Бориспіль и Запоріжжя.
- **Бизнес:** ФОП 2 группы, без НДС. Оплата WayForPay и LiqPay, наложенный платёж, рахунок для бизнеса. Чеки — Вчасно.Каса.
- **Цена:** по площади листа, округление до 10 ₴, минимум 150 ₴ (акрил 250 ₴). **Покупатель не видит м² и ₴/м² нигде.** Опт 10+ −5%, 50+ −10%, 100+ −15% (потолок 15%), оптовая программа −20% от 10 000 ₴/мес, скидки не складываются.
- **Ставки материалов** (₴/м², только админка): трафареты PET 0,5 — 2200, полистирол 1 мм — 2300, акрил 3 мм — 4000; заготовки — акрил по ставкам 10.10 (ТЗ §21: прозрачный 1,5–15 мм, цветной 4000, чёрный, молочный; есть оптовые ставки), зеркальный акрил 2/3 — 5600/8200, зеркальный полистирол 1 — 3600, ПЕТ 0,5 подложки — 1800; вывески 18 000 по габариту.
- **Станок:** лист до 1400 × 2000 мм, больше — составной, +5%.
- **Сроки:** изготовление 3 рабочих дня; дата отправки считается `lib/production.ts`.
- **Дизайн:** фон #FAFAFA, карточки белые, антрацит #0F172A для текста и всех кнопок, линии #E2E8F0, без синего и золота в интерфейсе; Inter + Unbounded; тёмная тема только в разделе B2B. Обоснование и история: `docs/design/`.
- **Кабинет:** вход Google или Telegram, без SMS.
- **Пищевой PET:** не пишем «харчовий/сертифікований», пока нет документов поставщика.
- **Каталог:** 18 разделов, папки под фото в `foto/` (`слаг - Название`).
