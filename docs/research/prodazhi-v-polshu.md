# Продажи в Польшу с ФОП 2-й группы из Украины

Исследование на 8 октября 2026. Это не юридическая консультация: налоги перед запуском сверить с бухгалтером. Общая схема продаж в ЕС и США описана в [prodazhi-v-es-i-ssha-iz-ukrainy.md](prodazhi-v-es-i-ssha-iz-ukrainy.md).

## Коротко

С ФОП 2-й группы продавать в Польшу можно: группа 2 может продавать **товары** иностранным покупателям, дополнительных налогов за экспорт нет ([Хорошоп](https://horoshop.ua/ua/blog/fop-export/)). Следите только за годовым лимитом дохода 2-й группы.

Реальная схема для старта:
1. **Свой сайт (польская версия)**: картой платят через Payoneer Checkout или украинский эквайринг, деньги приходят ФОП.
2. **Allegro** как второй канал: там поляки платят привычным BLIK, и оплату принимает сам Allegro.
3. **Доставка** из Украины Укрпочтой или Новой Почтой, с НДС и пошлиной, уплаченными заранее, чтобы покупатель ничего не доплачивал.
4. Позже: товар на складе Новой Почты в Варшаве, тогда доставка по Польше за 1–2 дня.

## 1. Оплата

Поляки больше всего платят через **BLIK** (код из банковского приложения), Przelewy24 и картами.

| Способ | Можно с ФОП из Украины? | Комментарий |
|---|---|---|
| Карты через Payoneer Checkout | Да | Официально для украинских предпринимателей, API для своего сайта, 0–3,5 %. [Payoneer](https://www.payoneer.com/resources/business/payoneer-checkout-what-is-it-and-how-does-it-work/) |
| Карты через WayForPay / LiqPay | Да | Иностранные карты, зачисление в гривне ФОП. [Хорошоп](https://horoshop.ua/ua/blog/fop-export/) |
| PayPal через Western Bid | Да, через посредника | Около 7 % в сумме. [Western Bid](https://westernbid.com/en/?p=22078) |
| BLIK / Przelewy24 на своём сайте | Практически нет | Их дают Stripe, PayU, Przelewy24, а им нужна компания в ЕС. Без неё BLIK доступен только через Allegro |

Деньги в валюте можно получать и на валютный счёт ФОП в украинском банке (monobank, ПриватБанк), а с Payoneer выводить туда же.

## 2. Allegro из Украины

- Allegro крупнейший маркетплейс Польши. По данным Хорошоп, продавать на нём **из Украины без польской фирмы можно**, после проверки документов. Комиссия только с продаж (примерно 4,5–10 % в зависимости от категории), подписка по желанию от 39 PLN в месяц. [Хорошоп о старте на Allegro](https://horoshop.ua/ua/blog/kak-nachat-prodavat-na-allegro/) *(статья 2022 года, правила для продавцов вне ЕС перед регистрацией надо проверить в справке Allegro)*
- Требования Allegro ко всем продавцам: **адрес для возвратов в Польше**, поддержка покупателей **на польском** и выгодная доставка. [ChannelEngine о требованиях Allegro](https://support.channelengine.com/hc/en-us/articles/4409503063069)
- При доставке из Украины нельзя предложить привычные полякам пачкоматы InPost и быструю доставку. Это компенсируют уникальным товаром: индивидуальные трафареты как раз такой товар.
- Сам Allegro сейчас идёт в Украину в обратную сторону: в 2026 году польские продавцы начали продавать украинцам, а отдельный Allegro.ua для украинских продавцов ожидается примерно в 2027 году. [Минфин](https://minfin.com.ua/ua/2026/05/26/174604702/)
- Посредники, которые открывают украинцам магазин на Allegro под ключ, существуют, но это платные агентства. Проверять их надо отдельно.

## 3. Доставка и таможня

- **С 1 июля 2026** для коммерческих посылок из Украины в ЕС: беспошлинного порога 150 € больше нет, пошлина **3 € за каждую товарную позицию** в декларации, плюс польский НДС 23 %. [Kurs.com.ua](https://kurs.com.ua/en/novost/1477500-ukrayinskii-biznes-uzhe-vidpraviv-50-tisjach-posilok-do-es-za-novimi-mitnimi-pravilami)
- **Укрпочта** по системе PDDP: продавец считает и платит НДС и пошлину онлайн в Украине, покупатель ничего не доплачивает. Коммерческие посылки оформляются через личный кабинет или API Укрпочты, сайт может делать это автоматически. По этой схеме уже отправлено больше 50 000 посылок, в основном в Германию, Францию и Польшу. [Kurs.com.ua](https://kurs.com.ua/en/novost/1477500-ukrayinskii-biznes-uzhe-vidpraviv-50-tisjach-posilok-do-es-za-novimi-mitnimi-pravilami), [Деньги.ua](https://dengi.ua/ua/tarif/9761158-posilki-do-jes-z-ukrayini-ukrposhta-poperedila-pro-novi-pravila-z-1-lipnya)
- **Новая Почта** доставляет в Польшу до пачкомата или курьером, плюс таможенное оформление для бизнеса. [Новая Почта для бизнеса](https://novaposhta.ua/for-business/international-delivery/how-to-send/)
- **Фулфилмент Новой Почты в Варшаве** (с мая 2025): товар хранится на таможенном складе до 90 дней без растаможки, растаможка и отправка идут уже после заказа. Даёт быструю доставку по Польше и польский адрес для возвратов, что нужно для Allegro. [Новая Почта](https://novaposhta.ua/en/news/fulfilment-poland/)
  *Для трафаретов под заказ склад подходит для готовых позиций, а индивидуальные всё равно идут из Украины.*

## 4. Что заложу в польскую версию сайта

- Польский язык, цены в злотых **с НДС 23 % и пошлиной** внутри цены, чтобы покупатель не доплачивал.
- Автоматическое оформление коммерческих посылок через API Укрпочты или Новой Почты.
- Обязательные для Польши страницы: регламент магазина (*regulamin*), политика конфиденциальности (RODO/GDPR), информация о возвратах. Индивидуальные трафареты можно законно исключить из 14-дневного возврата.
- Выгрузка товаров на Allegro из той же админки (через API Allegro), чтобы не вести два каталога.

## Что нужно от Дениса

1. Подать заявку в Payoneer Checkout на ФОП.
2. Открыть кабинет бизнес-клиента Укрпочты и/или Новой Почты для международных отправок.
3. Зарегистрироваться продавцом на Allegro и проверить, принимают ли сейчас ФОП из Украины и куда идут выплаты.
4. Решить, где будет адрес для возвратов в Польше: фулфилмент Новой Почты или знакомые и партнёры.
