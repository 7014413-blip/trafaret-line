# Дополнения в ТЗ: SEO (одобрено Денисом 08.10.2026)

Для ветки «Сайт Украина: разработка». Полное обоснование: `research/seo-plan-3-movy.md` (разделы в скобках). Сайт продаёт только трафареты и заготовки.

## Языки и адреса
1. Три языка: UA без префикса, `/ru/`, `/en/`. Язык только в адресе, без cookies и параметров; никаких редиректов по IP или языку браузера; переключатель — обычные ссылки на ту же страницу (§2).
2. Слаги: UA и RU — общий, транслит по КМУ-2010 (`sofiia`, `danylo`), генерируется из украинского названия с ручной правкой; у EN своё поле слага на английском (`/en/walls/mandalas/`). Связь версий — по ID страницы.
3. Товар по адресу `/p/{slug}/` без раздела (товар в нескольких разделах).
4. hreflang `uk-UA`, `ru-UA`, `en-UA`, `x-default` → UA-версия; в head на сервере и в sitemap. Поле настроек для будущего перекрёстного hreflang с trafaret-line.com.
5. canonical — на себя у каждой языковой версии. EN-версия публикуется только при флаге «перевод готов»; без перевода её нет в hreflang и sitemap.

## Индексация
6. SSR/SSG: в исходном HTML без JS — H1–H3, текст, цены, ссылки, мета, JSON-LD.
7. Фильтры и сортировка: параметры с `noindex, follow` + canonical на категорию; без перезагрузки индексируемого адреса. Админка: «посадочная из фильтра» со своим адресом, текстом, мета. Пагинация самоканонична, текст и FAQ только на 1-й странице. `/search/`, корзина, кабинет, оформление — noindex и robots.txt.
8. Конструктор: состояние в `?text=…` для «поделиться», с noindex + canonical на конструктор; отдельные статические посадочные под популярные фразы (`/konstruktor/just-married/` и т. п.), создаются в админке.
9. Sitemap: индекс + файлы по языкам (uk/ru/en) и типам (товары, категории, статьи), `lastmod` при правке. Google Indexing API **не использовать** (только вакансии и трансляции); вместо него Search Console + IndexNow (Bing). `llms.txt`.
10. Сезонные и снятые товары никогда не 404: статусы «Під замовлення», «Сезонний — передзамовлення», блок аналогов; удаление — только с 301 на аналог или раздел (редиректы в админке).

## Мета и разметка
11. SEO-поля на каждом языке отдельно: title, description, H1, текст, FAQ, alt. Шаблоны по умолчанию из §4 плана с ручной правкой.
12. JSON-LD: Organization (+sameAs), BreadcrumbList, Product/ProductGroup + hasVariant (размер × материал) с `name, image, description, sku, brand=Trafaret Line, offers (price, priceCurrency=UAH, availability, itemCondition)`, OfferShippingDetails, MerchantReturnPolicy; AggregateRating/Review только по реальным отзывам этого сайта; FAQPage; VideoObject; Article для гайдов; CollectionPage/ItemList для категорий; LocalBusiness только для реальных точек (Бориспіль, Запоріжжя; Київ — уточняется у Дениса). `inLanguage` по языку.
13. Отзывы: клиент прикрепляет фото/видео, модерация в админке; фото попадают в галерею товара и «Роботи клієнтів».
14. Поиск по сайту (Meilisearch): словарь синонимов имён и написаний (Софія/Софійка/София/Sofia). Скрытых тегов и meta keywords не делать.

## Скорость
15. Цель LCP ≤ 1,2 с, CLS ≈ 0 (лаб); обязательный минимум по полевым данным LCP ≤ 2,5 с, INP < 200 мс, CLS < 0,1; PageSpeed mobile 90+.
16. AVIF/WebP на сервере, Next/Image с width/height, srcset/sizes; главное фото `fetchpriority=high` без lazy.
17. Видео резки: WebM (VP9/AV1) + MP4 H.264 (не H.265), muted autoplay loop playsinline, постер, загрузка в зоне видимости.
18. Конструктор грузится отдельно, шрифты по запросу, превью в Web Worker. GTM, пиксели, чат — после загрузки; чат по клику.

## Магазин и B2B
19. Merchant-фид: UA основной (RU/EN — если Merchant Center примет язык для Украины); `identifier_exists=no`, `mpn`=артикул, `brand`, `material`, `size`, `custom_label` (маржа, сезон, раздел).
20. Кабинет оптовика (−20% от 10 000 ₴/мес): быстрый заказ по артикулам, загрузка CSV/Excel → счёт, история, сохранённые макеты и надписи, повтор заказа, уровень скидки.
21. Страницы доверия: «Виробництво» (фото/видео оборудования), «Для бізнесу» (реквизиты ФОП, счёт, оферта, опт, дропшиппинг), «Обмін і повернення» (кастом — только брак; готовые — 14 дней; проверить с юристом).

## Аналитика
22. GA4 ecommerce (view_item_list, view_item, add_to_cart, begin_checkout, purchase с товарами), язык страницы как параметр, фильтр ботов; Search Console (домен), Bing Webmaster, Merchant Center.

## Приёмка
23. Чек-лист из 21 пункта — §16 плана.
