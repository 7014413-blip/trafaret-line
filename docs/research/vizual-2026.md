## 2. Общие паттерны лидеров 2026

1. **Инфо-полоса сверху** с одним сообщением (бесплатная доставка/порог, сроки) — Rozetka, Makeup, Allbirds, Glossier, Stencil Revolution.
2. **Поиск — главный элемент шапки**: широкий, 40–48 px, в центре — Rozetka, Etsy, Epicentr; у брендов (Makeup, Aesop, Allbirds) — иконка.
3. **Кнопка «Каталог» + мега-меню / левый рельс** для широкого ассортимента — Rozetka, Epicentr; бренды — горизонтальное меню.
4. **Невысокий герой у маркетплейсов** (Rozetka ~170–300 px) и **бенто вместо карусели** (Etsy); полноэкранный — только у lifestyle-брендов (Aesop, Zara Home, IKEA).
5. **Категории фото-плитками или круглыми «сторис»** — IKEA, Allbirds, Stencil Revolution (плитки), Makeup (круги), Epicentr (иконки).
6. **Карточка: фото на белом/светло-сером, 1:1**, сердечко «в избранное» в углу фото — Rozetka, Etsy, IKEA, Glossier.
7. **Бейджи 1–2 типов** (Новинка/Хит/−%) — Rozetka, IKEA, Allbirds, Glossier, Epicentr.
8. **Цена: крупная новая + мелкая зачёркнутая старая**; акционная — красным — Rozetka, Epicentr, Stencil Revolution, IKEA.
9. **Рейтинг звёздами + число отзывов прямо в карточке** — Rozetka, Makeup, Etsy (Stencil Revolution — на уровне бренда).
10. **Быстрое действие из карточки** (иконка корзины / Quick add / Quick look) — Rozetka, Glossier, Stencil Revolution.
11. **Варианты чипами и свотчами, не выпадающими списками** — Allbirds, Glossier, Apple **[Apple не проверено]**.
12. **PDP: галерея слева, buy-box справа, сразу под кнопкой — доставка со сроками и ценой**, оплата частями — Rozetka, Allbirds.
13. **Вкладки/аккордеоны вместо простыни текста** — Rozetka (вкладки), Allbirds (аккордеоны).
14. **Мобайл: нижняя навигация + липкая цена/кнопка** — Rozetka (нижнее меню, цена прибита внизу); NN/g и сторонние аудиты фиксируют рост добавлений в корзину от липкой кнопки **[цифра 12–18% не проверена в первоисточнике]**.
15. **Скелетон-загрузка и микроанимации** (подтверждение «Added to cart», hover) — Rozetka (скелетоны), Allbirds (уведомление о добавлении); тренд-обзоры 2026 называют микровзаимодействия, бенто-сетки и крупную типографику главными визуальными трендами.

## 3. Рекомендации для Trafaret Line

**Оставить:**
- Светлый фон, тёмно-синий текст, ОДИН насыщенный синий для кнопок покупки — так делают все лидеры (один акцент действия). Добавить только красный для акционной цены и зелёный для «в наличии».
- Inter для текста. Unbounded — только для H1/H2 и крупных цифр цены в герое; в карточках и меню — Inter (Unbounded широкий, в узкой карточке съест место).
- Левый рельс каталога на десктопе (как Rozetka) — но только на главной; на остальных страницах — кнопка «Каталог» с мега-меню.
- Ленты товаров с вкладками («Хіти / Новинки / Акції»).

**Изменить / добавить:**
- **Герой:** не выше 320–360 px на десктопе (рядом с рельсом), 3–5 слайдов максимум, без автопрокрутки на мобайле, видимые стрелки внутри баннера (NN/g). Альтернатива — бенто: 1 большой + 2 малых блока, тогда главные акции видны сразу.
- **Шапка:** тонкая инфо-полоса 32–36 px («Безкоштовна доставка від N грн · Відправка в день замовлення»); поиск 44–48 px по центру, радиус 12 или пилюля, с подсказками по мере ввода.
- **Категории:** плитки с фото готового результата (узор на стене/торте/ткани), а не иконки — трафарет продаётся результатом. Для блоков-заготовок (акрил/ПЭТ) — плитки с фото материала + подпись толщины. На мобайле — горизонтальный ряд кругов/чипов.
- **Карточка:** фото 1:1 на светло-сером (#F4F6F9), радиус карточки 12–16 px, без тени в покое, лёгкая тень/подъём на hover; сердечко в углу фото; максимум 1 бейдж; размер чипом прямо в карточке («30×40 см»); цена 18–20 px жирным, старая 13–14 px зачёркнутая; звёзды + число; иконка-кнопка корзины 40×40 синим.
- **Чипы-фильтры** над сеткой (размер, тема, материал, толщина) + полный фильтр слева на десктопе / bottom sheet на мобайле.
- **PDP:** галерея слева с фото «в работе» и видео; справа: название, рейтинг, цена, **размеры и толщина — чипами**, количество, «Купити» + «Купити в 1 клік», под ними блок доставки (Нова Пошта/Укрпошта, ориентировочная дата, цена, порог бесплатной), «Оплата частинами». Ниже — вкладки «Опис / Характеристики / Відгуки / Як користуватись».
- **Мобайл:** нижняя навигация (Головна, Каталог, Пошук, Обране, Кошик) + липкая полоса «цена + Купити» на PDP; зона большого пальца для главных действий.
- **Чекаут:** одна страница, гость без регистрации, 7–8 полей (Baymard: идеал 12–14 элементов формы, средний сайт — 23,48), стоимость доставки видна до последнего шага (40% бросают корзину из-за неожиданных расходов, 18% — из-за обязательной регистрации).
- **Доверие у героя/в футере карточки:** «Відправка за 1 день», «Свій виробник», «N відгуків» — как Stencil Revolution.
- **Радиусы:** кнопки/поля 10–12 px, карточки 16 px, баннеры 20 px, чипы — пилюля. **Тени:** почти не использовать, разделять фоном. **Отступы:** 8-px сетка, между секциями 56–72 px на десктопе.
- **Размеры шрифта:** база 16 px, H1 40–48 px, H2 28–32 px, название в карточке 14–15 px (2 строки, обрезка), подписи 12–13 px.
- **Моушн:** 150–250 мс ease-out на hover/добавление, анимация «летящего» счётчика корзины, скелетоны вместо спиннеров; без параллакса.
