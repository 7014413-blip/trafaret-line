Связано: vizual-magaziniv-2026.md (белый фон, один акцент, видео на первом экране), voronka-prodazh.md, algoritm-konstruktora.md, TZ.md. Всё ниже — предложения для макетов и ТЗ.

## Часть 1. Как вызвать эмоцию

Главная эмоция для нас — **«я тоже так смогу, и это будет красиво»**. Трафарет покупают ради результата (стена, торт, подарок, шлем), поэтому показываем результат и лёгкость, а не пластик.

### 1. Видео и движение
- **Первый экран:** вертикальное видео 6–8 с: валик проходит по трафарету, трафарет снимают — на стене рисунок. Без звука, зациклено, до 1,5 МБ, на телефоне сначала картинка-постер.
- **Карточка товара:** первое фото — результат на поверхности, второе — сам трафарет, третье — масштаб (рулетка, рука), четвёртое — видео «як нанести» 20–40 с.
- **Конструктор:** при вводе текста буквы «вырезаются» на превью (короткая анимация 200 мс), при смене вкладки «На стіні» трафарет «прикладывается» к стене.
- Уважать «уменьшение движения» в системе телефона: тогда только картинки.

### 2. «До / після»
- Слайдер-шторка на главной и в категориях стен, мебели, штукатурки: голая стена → стена с мандалой.
- В гайдах: шаги с фото (подготовка → наложение → покраска → снятие).

### 3. Истории клиентов (самое сильное)
- Блок «Роботи наших клієнтів»: фото + имя + город + одна фраза («Пофарбувала дитячу за вечір, Оля, Дніпро»).
- Кейсы B2B: кофейня с логотипом на латте, ОСББ с номерами подъездов, воинская часть с піксель-камуфляжем (с разрешения).
- Отзывы с фото выше отзывов без фото; купон −10% за фото работы (из воронки).
- Счётчик доверия только с реальными цифрами: «Вирізали N трафаретів», «N відгуків» (не выдумывать).

### 4. Тексты
- Говорим о результате и чувстве, коротко, на «ти/ви» единообразно (предлагаю «ви»):
  - «Стіна, як із журналу, за один вечір»
  - «Ваш напис на торті — точно як задумали»
  - «Ріжемо самі: побачите ціну одразу, отримаєте за 3 робочі дні»
- Кнопки глаголом: «Обрати трафарет», «Зробити свій», «Купити».
- Микротексты с теплом: пустая корзина — «Тут поки порожньо. Почнемо з мандали?»; после заказа — «Дякуємо! Ми вже готуємо макет, превʼю надішлемо у Viber».

### 5. Микроанимации (тонко, не цирк)
- Цена «перелистывается» при смене размера/материала.
- Кнопка «Купити» — короткий отклик при нажатии, товар «летит» в корзину.
- Чипы выбора — плавная подсветка, галочка.
- Скелетоны вместо спиннеров при загрузке.

### 6. Персонализация и сезон
- Главная меняет сцену по сезону: новогодние окна (с конца октября), Пасха (февраль–март), 1 вересня и весілля (июль–август), День Незалежності (август).
- «Ви дивились» и «Разом купують» на карточке.
- Патриотический блок (тризуб, піксель ЗСУ) — с уважением, без кричащего дизайна.

### Чего не делать
Автокарусели, всплывающее окно при входе, таймеры «осталось 2 часа», фейковые счётчики «купили 37 человек», музыка, параллакс, тяжёлые 3D-эффекты (медленно на телефоне).

## Часть 2. Чат-бот помощник

### Что умеет (по приоритету)
1. **Подобрать трафарет:** «хочу щось на стіну в дитячу 1,5 метра» → 3–6 карточек из каталога со ссылками, с размерами и ценой.
2. **Посчитать размер и цену:** «надпис "Кава" 40 см на акрилі» → цена по той же формуле, что на сайте (TZ §3.3), ссылка в конструктор с уже заполненными полями.
3. **Ответить на вопросы:** какой материал для штукатурки, как наносить, сроки, доставка, оплата, опт — из базы гайдов и FAQ (только наши тексты, не выдумывать).
4. **Статус заказа:** по номеру заказа или телефону → статус из CRM Топерок + трекинг по ТТН через API Нової пошти.
5. **Принять заявку B2B:** собрать что нужно (размер, количество, макет файлом, контакты) → создать лид в CRM.
6. **Передать менеджеру:** кнопка «Зв'язатися з людиною» в любой момент, и автоматически при сложном вопросе, жалобе, макете на проверку. Менеджер отвечает из Telegram, история диалога у него перед глазами.

Чего бот не делает: не обещает скидок и сроков, которых нет в правилах; не принимает оплату в чате (даёт ссылку на оформление); не показывает чужие заказы (проверка по телефону + номеру заказа).

### Где живёт
| Канал | Зачем | Примечание |
|---|---|---|
| Виджет на сайте | главный: подбор, цена, ссылки на карточки | кнопка в правом нижнем углу, на телефоне не перекрывает «Купити» (поднимается над липкой панелью) |
| Telegram-бот | статусы заказа, B2B, повторные заказы | Bot API бесплатный |
| Viber | в Украине им пользуется много покупателей, туда же шлём превью макета | у Viber чат-боты для бизнеса платные (условия меняются — уточнить перед запуском); на старте можно Viber только для уведомлений менеджера |
| Prom / Rozetka | — | там свои чаты, бот не подключаем, отвечает менеджер |

### На чём сделать недорого
**Вариант А (рекомендую):** свой небольшой сервис рядом с сайтом.
- Модель: Claude API (быстрая и недорогая модель семейства Claude 5 для диалога; сложные случаи — передача человеку). Оплата за использование, без абонплаты; точную стоимость посчитать по прайсу Anthropic после оценки числа диалогов.
- Инструменты (tool use), которые бот вызывает: `search_catalog` (поиск по нашему каталогу Medusa), `calc_price` (тот же модуль цены, что на сайте), `order_status` (CRM + Нова пошта), `create_lead` (CRM), `handoff_to_manager` (Telegram менеджеру).
- Знания: гайды, FAQ, условия доставки и оплаты из админки сайта — бот отвечает только по ним.
- Хостинг: тот же VPS Hetzner, что и сайт.
- Плюсы: точные цены и реальные товары, никакой абонплаты за платформу, всё в одной CRM.

**Вариант Б (быстрый старт):** готовая платформа виджета чата (с ИИ-ответами по базе знаний) с подключением Telegram. Быстрее запустить, но ежемесячная подписка и бот не знает живых цен и остатков без доработки.

### Правила качества
- Отвечает на языке клиента (UA/RU), коротко, с кнопками-ссылками на товары.
- Каждый ответ с ценой проверяется тем же модулем цены, что и корзина.
- Логи диалогов: что спрашивают и где бот сдаётся → новые гайды, FAQ и товары.
- Метрики: доля диалогов, закончившихся переходом в карточку / корзиной, % передач менеджеру, оценка «👍/👎».

### Порядок запуска
1. Виджет на сайте: подбор + цена + FAQ + передача менеджеру в Telegram.
2. Статус заказа по ТТН и CRM.
3. Telegram-бот для клиентов, B2B-заявки.
4. Viber — после проверки условий и стоимости.
