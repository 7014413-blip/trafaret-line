# Алгоритм конструктора индивидуального трафарета (2026-10-08)

Основа: пожелание Дениса («написал, выбрал шрифт, сразу видно на картинке, выбрал размер прямоугольный/квадратный, сразу цена, купить, плюс материал»), ТЗ §3.3 и §4.5, прототип https://claude.ai/artifact/DkTupfV9AfSPFeyRaB1coA (3 строки текста, 2 шрифта, ширина в см, 4 материала, вкладки «Трафарет / На стіні / Файл різки», перемычки 2,5 мм, поле 15 мм, минимум 150 ₴ / акрил 250 ₴, опт от 3 шт.).
Цены сверять с KONCEPCIYA.md и TZ.md, прайс ведёт ветка «Сайт Украина: разработка».

## Главный принцип
Один экран, без пошагового мастера. Слева (на телефоне сверху) превью, справа (на телефоне снизу) настройки. Всё заполнено значениями по умолчанию, поэтому покупатель **сразу** видит готовый трафарет и цену, а дальше только меняет то, что хочет. Любое изменение перерисовывает превью и цену меньше чем за 0,2 с, без кнопки «Применить».

## Порядок блоков на экране (сверху вниз)
1. **Превью** с вкладками: «Трафарет» (белый лист с прорезями) · «На стіні / на торті / на склі» (мокап в реальном масштабе) · размеры листа и высота букв подписаны прямо на картинке.
2. **Текст**: одно поле, Enter = новая строка (до 4 строк). Подсказки-шаблоны чипами: «Своє ім'я», «Номер будинку», «Кава з логотипом», «Весілля + дата», «Обережно».
3. **Шрифт**: горизонтальная лента чипов, каждый чип написан ЭТИМ шрифтом и показывает ТЕКСТ покупателя (не «Aa»). 10 на старте, 20 позже. Группы: Класичні · Рукописні · Шрифти-трафарети · Жирні для вивісок · Військові/технічні (DIN, ГОСТ).
4. **Форма и размер**:
   - Форма: Прямокутник · Квадрат · Коло (на старте 3; «Овал», «Своя ширина×висота» позже).
   - Размер чипами с ценой на каждом: А5 · А4 · А3 · А2 (для прямоугольника), 20 · 30 · 40 · 50 · 60 см (квадрат/круг) + «Свій розмір» (поле ширины в см, высота считается сама).
   - Под чипами строка: «Аркуш 42×30 см · висота літер 8,4 см».
5. **Материал**: 3–4 карточки с одной строкой «для чего»: ПЕТ 0,5 (фарба, стіни, торти) · Полістирол 1 мм білий/чорний (штукатурка, багаторазово) · Акрил 3 мм (жорсткий, на роки). Цены на чипах размера пересчитываются под материал.
6. **Количество** (− 1 +) и плашки опта: 1 · 3+ · 10+ · 50+ с ценой за штуку.
7. **Итог**: крупная цена, срок «Виготовлення 3 робочі дні», кнопки «Купити» и «Замовити за телефоном». На телефоне цена и «Купити» в липкой нижней панели.

## Алгоритм (что происходит после каждого действия)
```
state = {text, font, align, spacing, shape, size|customWidth, material, qty, surface}

on change(state):
  1. glyphs   = opentype.layout(text, font, align, letterSpacing, lineSpacing)
  2. bridges  = для каждого внутреннего контура (О, А, Б, Р, Я, Ю, Д, 0, 4, 6, 8, 9…) добавить перемычку ≥ 2,5 мм
                (для шрифтов-трафаретов перемычки уже в шрифте → пропустить)
  3. sheet    = размер выбранного чипа или customWidth × высота по пропорции текста
  4. fit      = вписать текст в лист с полем 15 мм (кругу: вписать в квадрат внутри круга; позже текст по дуге)
  5. letterH  = реальная высота заглавной буквы в мм
  6. checks:
       letterH < минимум_шрифта_для_материала  → жёлтое предупреждение + чип «Збільшити до …»
       перемычка или деталь тоньше 1,5 мм       → подсветить место красным на превью
       лист > 1400×2000                          → «Буде складений з N частин, +5%»
       пустой текст / символ не из шрифта        → подсказка, «Купити» неактивна
  7. price    = max(минимум_материала, округл_до_10(площадь_листа × ставка_материала × коэф_сложности))
                × скидка_опта(qty) × скидка_площади (1–3 м² −15%, от 3 м² −25%)
  8. render   = SVG превью + мокап (масштаб из справочника мокапов) + подписи размеров
  9. save     = состояние в URL (?t=…&f=…) → ссылкой можно поделиться, после перезагрузки ничего не теряется

on «Купити»:
  сервер пересчитывает цену (клиенту нельзя подменить), генерирует SVG+DXF в мм,
  кладёт позицию в корзину с картинкой превью и параметрами,
  обещание: «Перевіримо макет і надішлемо превʼю у Viber до порізки».
```

## Значения по умолчанию (чтобы превью было с первой секунды)
- Текст: из шаблона страницы (на странице «Весілля» — «Just Married», на главной — «Ваш напис»).
- Шрифт: самый продаваемый для раздела (кондитерский — рукописный, вывески — жирный без засечек).
- Форма: прямоугольник, размер А4, материал ПЕТ 0,5, количество 1, выравнивание по центру.

## Что ещё добавить (предложения)
**Обязательно на старте**
1. Выравнивание: по левому краю / по центру / по правому краю.
2. Межбуквенный интервал (−2…+5) и межстрочный (ползунок): для трафаретов важно, чтобы буквы не слипались.
3. «Великі літери» (переключатель) и «Дзеркально» (для нанесения на стекло изнутри).
4. Режим размера «за висотою літер»: для номеров домов, разметки и маркировки покупатель знает «буквы 10 см», а не размер листа.
5. Подсказка с масштабом: силуэт человека / торт Ø20 / чашка рядом, чтобы понять реальный размер.
6. Шаблоны-заготовки (чипами): имя, номер дома, «Wi-Fi», «Кава», «Just Married + дата», «Обережно», номер подъезда.

**Вторым этапом**
7. Текст по дуге для круга (торты, кава, печати).
8. Рамка/бордюр вокруг текста и простые элементы: сердце, звезда, листочек, тризуб, стрелка.
9. Загрузка логотипа рядом с текстом (тогда заказ уходит на проверку менеджеру, как в «По вашому макету»).
10. Набор «по буквам»: каждая буква отдельным трафаретом (для больших надписей и разметки), цена за набор.
11. Сохранение в кабинете и «Повторити замовлення» для B2B.
12. Сравнение материалов на превью (как выглядит ПЕТ и акрил).

**Не делать**
- Пошаговый мастер с кнопкой «Далі» на каждом шаге: покупатель не видит результат и уходит.
- Выпадающие списки для шрифта и размера (как на topperok): только чипы с видимой ценой.
- Цена «від» или «менеджер порахує» для обычной надписи: цена всегда точная, на экране.
- Регистрация до покупки.
