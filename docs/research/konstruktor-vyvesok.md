# Конструктор вывесок и букв из акрила

08.10.2026. Источник: голосовое Дениса (вывески из многослойного акрила, буквы и слова из акрила, 18 000 грн/м²) и его промпт-ТЗ (слои для лазера, отверстия под крепёж, перемычки). Утверждённое не меняем: палитра сайта #FAFAFA / #0F172A / #E2E8F0, золото только как цвет материала, лёгкий CSS-эффект вместо Three.js, языки UA/RU/EN, цена по площади.

Прототип: см. ссылку в ветке «Конструктор вывесок». Пометка **[Предложение]** = моё предложение, ждёт решения Дениса.

## 1. Что продаём

| Товар | Что это | Как считаем |
| --- | --- | --- |
| **Бизнес-вывеска** | основа (круг/квадрат/прямоугольник) + 1–4 накладных слоя из акрила (текст, логотип, рамка) | 18 000 грн/м² по габариту основы (см. §5) |
| **Стрелки и указатели** | та же вывеска, основа в форме стрелки или указателя («ВХІД →», «Каса ←»), направление влево/вправо | как вывеска, 18 000 грн/м² по габариту |
| **Буквы и слова из акрила** | отдельные вырезанные буквы или слово одним куском, без основы | по габариту слова × ставка материала × коэффициент (см. §6) |
| **Заготовки** (уже есть в ТЗ) | круги, квадраты, прямоугольники без нанесения | цена заготовок из ТЗ |

Связь: на странице заготовки «Акриловый круг» кнопка «Сделать вывеску на этом круге» открывает конструктор с уже выбранной основой. Так продажа заготовки апсейлится в вывеску.

## 2. Шаги конструктора (одна страница, без «мастера» из 7 экранов)

1. **Основа:** толщина из того, что уже продаётся в заготовках (акрил 1,5 / 3 / 6 / 8 мм, зеркало 2 / 3 мм), 6 и 8 мм дают доплату (§5); форма (круг / квадрат / прямоугольник / скруглённый прямоугольник / стрелка / указатель с направлением ←/→), размер в мм (пресеты 300, 400, 500, 600 + своё значение), материал основы (зеркальный серебро/золото, цветной акрил, прозрачный, белый, чёрный), толщина.
2. **Содержимое:** вкладка «Текст» (до 3 строк, шрифт, по дуге или прямо) или «Загрузить свою вывеску/логотип» (SVG, PDF, AI, DXF, PNG, JPG; разбор по цветам в слои автоматически, §7).
3. **Слои и цвета:** список слоёв; у каждого свой акрил из палитры одним нажатием. Для логотипа каждый цвет файла = отдельный слой, конструктор сам подбирает ближайший акрил из палитры, клиент может поменять.
4. **Крепление:** без отверстий / 2 / 4 отверстия под дистанционные держатели (Ø6 мм, центр 20 мм от края). Отдельная галочка **«Самоклейка на обороте»** (двусторонний скотч) — доплата по площади, доступна и для букв без основы (Денис 08.10).
5. **Проверка и цена:** цена пересчитывается мгновенно при любом изменении размера, материала, слоёв или крепления (Денис 08.10: клиент сразу видит стоимость и оформляет). конструктор показывает предупреждения (§4), цену, срок и кнопки «В кошик» / «Отправить менеджеру».

Предпросмотр всё время на экране: фон «стена» / «светлый» / «тёмный», лёгкий CSS-объём (тень толщины, блик на зеркале). Переключатель «Вид для производства» показывает линии реза по слоям (§7), без скачивания файла.

## 3. Модель данных (новый файл `types/signage.ts`, общие не трогаем)

```ts
type SignShape = 'circle' | 'square' | 'rect' | 'rounded';
type AcrylicId = string;                      // ключ из палитры, напр. 'mirror-silver-3', 'black-3'

interface AcrylicSheet {                      // палитра, редактируется в админке
  id: AcrylicId; name: Record<'uk'|'ru'|'en', string>;
  hex: string; finish: 'mirror'|'gloss'|'matte'|'clear';
  thicknessMm: number; pricePerM2: number;    // ставка для букв и заготовок
  inStock: boolean;                           // нет в наличии = серый чип «під замовлення»
}

interface SignBase { shape: SignShape; widthMm: number; heightMm: number; cornerMm?: number; material: AcrylicId }

interface SignLayer {
  id: string; order: number;                  // 1 = ближе к основе
  kind: 'text' | 'arcText' | 'logoColor' | 'frame';
  material: AcrylicId;
  text?: string; font?: string; heightMm?: number; // высота заглавной буквы
  svgPaths?: string[];                        // для логотипа: контуры одного цвета
  sourceColor?: string;                       // исходный цвет из файла
  x: number; y: number; rotation: number;     // мм от центра основы
}

interface SignDesign {
  base: SignBase; layers: SignLayer[];
  mount: { type: 'none'|'holes2'|'holes4'|'tape'; holeDiaMm: 6; edgeOffsetMm: 20 };
  warnings: SignWarning[];                    // считаются, не хранятся
}
```

Сохранение: в Zustand с persist (черновик в браузере) + в личном кабинете как «сохранённый макет» (уже утверждено для трафаретов).

## 4. Правила и проверки

| Правило | Значение | Что делает конструктор |
| --- | --- | --- |
| Мин. высота буквы накладного слоя | 15 мм для 3 мм акрила, 25 мм для зеркала 2 мм **[Предложение, подтвердить на станке]** | жёлтое предупреждение, «В кошик» остаётся |
| Мин. толщина линии (штриха) | 2 мм (3 мм акрил), 3 мм для зеркала **[Предложение]** | шрифты с тонкими штрихами помечены «від N мм»; тонкие элементы логотипа подсвечены |
| Отступ слоя от края основы | ≥ 10 мм | слой подсвечивается красным контуром |
| Отверстия под крепёж | Ø6 мм, центр в 20 мм от края (диапазон 15–20 мм из ТЗ Дениса) | отверстие не должно попадать на слой: если попадает, сдвигаем отверстие или предупреждаем |
| Мелкие внутренние детали | «острова» меньше 3×3 мм не вырезаются | при разборе логотипа удаляем с пометкой |
| Перемычки | **для накладных букв не нужны** (буква клеится целиком, «О» и «А» вырезаются с отверстием); нужны только для трафаретов и для шаблона позиционирования (слой 4) | автоматически только в трафаретном слое |
| Макс. размер | по рабочему полю лазера Дениса **[вопрос]** | больше поля = «под заказ, менеджер свяжется» |

Важно про перемычки: в промпт-ТЗ они стоят для всех букв, но для вывески это ошибка, буква вырезается целиком, внутренний контур «О» выпадает и это нормально. Перемычки нужны только в трафарете-шаблоне для поклейки.

## 5. Цена вывески: 18 000 грн/м²

**Ставка изменена Денисом 08.10: 18 000 грн/м² вместо 15 000.** Ставка — настройка в админке.

**УТВЕРЖДЕНО Денисом 08.10 (21:51):** вывеска из двух слоёв пластика = 18 000 грн/м² по габариту; основа 3 мм, накладной слой 1, 2 или 3 мм на выбор клиента (входит в цену); основа толще — доплата разницы.

**Толщина (Денис 08.10):** 18 000 включает основу 3 мм и накладные слои 1–3 мм (цветной, зеркальный и т. д.). Если основа толще, к ставке добавляется разница цены листа против 3 мм по прайсу заготовок (считается автоматически из ставок материалов в админке): акрил 6 мм +3 600 грн/м² (6 500 − 2 900), 8 мм +5 100 грн/м² (8 000 − 2 900). Тоньше 3 мм (1,5 мм, зеркало 2 мм) цену не снижает. Пример: 50×50 см на 6 мм = 0,25 × 21 600 = 5 400 грн. Клиент видит только строку «Основа 6 мм замість 3 мм: +900 грн». Накладные слои толще 3 мм не предлагаем.

**Клиенту м² не показываем нигде (Денис 08.10).** Клиент вводит размеры в мм/см и видит только итоговую цену изделия и понятные строки: размер, материал, число слоёв, отверстия, «самоклейка +N грн». Ставки за м² живут только в админке. Это же правило действует для трафаретов и заготовок. Расчёт по м² виден только администратору.

**Решение Дениса (08.10):** многослойная и разноцветная вывеска стоит 18 000 грн/м², что бы клиент ни выбрал. Все слои, цвета и материалы (зеркальный, цветной, двухслойный пластик) уже входят в цену. Самоклейка на обороте оплачивается отдельно.

**Площадь = общий габарит вывески (подтвердил Денис 08.10):** прямоугольник, в который она вписана. Пример: 50×50 см = 0,25 м² × 18 000 = 4 500 грн. Круг Ø400 считаем как 400×400.

```
area  = widthMm × heightMm / 1e6
price = area × 18 000 (RATE_SIGN, админка)
      + area × max(0, sheet(t) − sheet(3 мм))      // доплата за основу толще 3 мм
      + (tape ? area × TAPE_RATE : 0)    // самоклейка, цена не названа; в прототипе заглушка 600 грн/м²
price = max(price, MIN_SIGN_PRICE)       // минимум 1 500 грн [Предложение]
price = ceil(price / 10) × 10
```
Примеры: Ø300 = 0,09 м² → 1 620 грн; Ø400 → 2 880 грн; Ø500 → 4 500 грн; 600×400 → 4 320 грн; указатель 500×150 → 1 350 → минимум 1 500 грн.

Скидки: общие правила из `research/sistema-skidok.md` (одна лучшая скидка, опт до 15 %, оптовики 20 %).

## 6. Буквы и слова из акрила (без основы)

Отдельная страница товара «Літери та слова з акрилу» с тем же конструктором, но без основы.

```
area = габарит слова (ширина × высота заглавной + выносные) в м²
price = area × pricePerM2(материал, толщина) × K
K = 2,0 для отдельных букв, 1,5 для слова одним куском **[Предложение]**: много реза на маленькой площади
минимум 250 грн (как акрил в ТЗ), шаг 10 грн
```
Ставки материала берём из ТЗ: акрил 3 мм 2 900, 6 мм 6 500, 8 мм 8 000, зеркало 2 мм 5 600, 3 мм 8 200, цветной 5 200. Опция «монтажный трафарет» 600 грн/м² (§7а).

## 7. Загрузка логотипа и экспорт для лазера

**Файл всей вывески с реальным размером (Денис 08.10):** если в SVG/PDF/AI/DXF указан размер в мм, см, дюймах или пунктах, конструктор берёт общий габарит из файла: размер основы и цена ставятся сами. Цвет, который заполняет весь контур, становится материалом основы, остальные цвета — слоями. Если нужного цвета нет в палитре, клиент всё равно загружает свой файл, а цвет подбирается ближайший или уточняется менеджером. Проверки края и отверстий для логотипа идут по реальному контуру, а не по рамке.

**Загрузка готовой вывески или логотипа (дополнение Дениса 08.10):** клиент загружает файл, сайт сам разбирает его по цветам в слои, и дальше клиент работает с ним в конструкторе как с обычными слоями: меняет акрил каждого цвета, двигает, масштабирует, добавляет текст и рамку.
- **SVG** — разбор в браузере: собираем `fill` всех фигур, группируем по цвету, каждая группа = слой. Близкие оттенки (антиалиасинг, шум экспорта) склеиваем. К каждому цвету автоматически подбирается ближайший акрил из палитры. Работает в прототипе.
- **PDF / AI / EPS** — сервер переводит в SVG (Inkscape CLI; AI с 9-й версии внутри PDF), дальше как SVG. Для клиента это та же загрузка, разбор занимает пару секунд.
- **DXF** — слои или цвета ACI → наши слои (`dxf-parser` на сервере).
- **CDR** — просим сохранить в PDF или SVG (открытого конвертера нет).
- **PNG / JPG / WEBP** — автоматическая векторизация: убираем фон, сводим к 2–5 цветам, каждый цвет = слой. На сайте контуры строит сервер (potrace), в прототипе показана упрощённая версия в браузере. Клиент видит предупреждение «переведено автоматически, менеджер проверит контуры перед резкой», а заказ получает статус «нужна проверка макета». Если картинка плохая (мелкая, размытая, фото), менеджер предлагает платную отрисовку [вопрос о цене].
- Текст в файле, не переведённый в кривые, → предупреждение «переведите текст в кривые».
- После разбора работают все проверки §4: мелкие детали, отступ от края, отверстия.

**Экспорт (только после оплаты, как уже утверждено для трафаретов):** SVG + DXF, мм, по слоям с цветами, которые RDWorks понимает как разные слои:

| Слой | Цвет | Содержимое |
| --- | --- | --- |
| 1 Основа | красный #FF0000 | контур основы |
| 2 Накладные | синий #0000FF | контуры букв и логотипа, отдельный файл на каждый материал |
| 3 Отверстия и метки | зелёный #00FF00 | отверстия Ø6, метки совмещения |
| 4 Монтажный трафарет | чёрный #000000 | контуры букв +0,2 мм на картоне/HDF, лист = контур основы |

Раскладка по листам: один файл на материал (зеркало серебро, чёрный 3 мм и т. д.), чтобы оператор резал лист за листом. Скорость и мощность в файл не пишем, их ставит оператор в RDWorks.

## 7а. Монтажный трафарет и B2B (Денис 08.10)

**Монтажный трафарет для поклейки** (галочка в конструкторе «Монтажний трафарет (картон / HDF)»):
- Цена 600 грн/м² по габариту вывески (для букв без основы: габарит надписи + 20 мм с каждой стороны). Клиент видит «+N грн».

**Для агентств (B2B, дропшиппинг):**
- **White-label:** галочка «Без нашого бренду». Коробка, вкладыш и накладная без нашего логотипа и без цен, отправка сразу конечному клиенту агентства. Цена опции: бесплатно [Предложение]. ТТН от имени агентства, без нашего бренда и цен в посылке; тот же переключатель будет в оформлении трафаретов (ветка «Интерактивные фишки дизайна»). Вес и упаковку посылки берём из `code/ui-components/lib/parcel.ts`, налоговые правила ФОП 2 из `research/dostavka-i-nalogi.md`.
- **Коммерческое предложение PDF:** кнопка в конструкторе. В PDF: макет на стене с лёгким 3D-наклоном (CSS, не Three.js), размеры в см, основа и толщина, слои и их акрил, крепление, самоклейка, монтажный трафарет, срок, цена для конечного клиента = наша цена + наценка агентства (поле %, по умолчанию 30). Номер КП, дата, срок действия 7 дней. При white-label вместо нашего логотипа — логотип агентства (загружается в личном кабинете). Наша цена и наценка в PDF не попадают. На сайте PDF генерируется на сервере (Playwright → PDF), так как в браузере это ненадёжно.

## 10. Передача в разработку

Код (TypeScript, strict, проверен tsc и тестом цен):
- `code/ui-components/types/signage.ts` — модель вывески, палитры, настроек цены, проверок.
- `code/ui-components/lib/signage-math.ts` — `priceSign()` (цена + строки для клиента без м²), `verifySignPrice()` (сервер), `checkSign()`, `signHoles()`, `signOutline()`, `signHolesForExport()` (стыкуется с `lib/export-layers.ts`), `ACRYLIC_PALETTE`, `DEFAULT_SIGN_PRICING`. Скидки — через `bestLineDiscount()` из `stencil-math.ts`, не суммируются.
- Проверено: 50×50 = 4 500; на 6 мм = 5 400; с монтажным трафаретом = 4 650; 25×25 → минимум 1 500; Ø400 = 2 880.
- Прототип интерфейса: `research/konstruktor-vyvesok-prototip.html` (ссылка в начале).

Что делает ветка разработки:
