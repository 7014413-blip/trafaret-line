# План до 10 из 10 — критерии приёмки QA

Это чек-лист для разработки и критерий повторного теста. Оценка 10 по области ставится, только когда **все** пункты области выполнены и проверены QA. Приоритет: **P0** — без этого не запускаемся, **P1** — до запуска рекламы, **P2** — до конца первого месяца.

Текущие оценки взяты из [QA-отчёта](QA_отчёт_2026-10-10.md). Коды находок (C1, M1, m1…) — оттуда же.

## Порядок работ
1. P0 безопасности и оплаты (C1, M9, M8, M3, M4) и сборка (C2).
2. P0 цен и опта (M1, M2).
3. P0 оферта и политика (M7), языки или скрытие переключателя (M5).
4. P0 SEO (robots, sitemap, canonical, hreflang).
5. Живой проход QA: мобильная версия, доступность, Lighthouse → появятся пункты P0/P1 по этим областям.
6. P1 по всем областям, затем повторный полный прогон.

**Критерий итоговых 10/10:** все P0 и P1 закрыты, Lighthouse mobile ≥ 90 по всем четырём категориям, axe без critical/serious, повторный e2e-прогон без ошибок, 0 critical и 0 major в отчёте QA.
