# База знаний проекта «Магазин трафаретов»

Всё, что нужно для работы над сайтом. Обновлено 8 октября 2026. Новые материалы добавлять сюда же.

## Решения и стратегия
- [Категории каталога трафаретов](https://claude.ai/code/artifact/05a28b80-cd06-4b56-854a-8196d74b99e0) (Claude Doc, 2026-10-08): 14 ниш, дерево категорий с URL, фильтры, порядок наполнения, сезонный календарь.
- [Стратегия магазина трафаретов](https://claude.ai/code/artifact/2e2d2cb2-7fff-457a-b2e1-576ce9fd41d1) (Claude Doc): ниша из 9 сегментов, планка лидеров и стандарт запуска, структура каталога, три пути индивидуального заказа, каналы, план по этапам, что нужно от Дениса.
- Технологии (предложены, Денис склоняется к ним): Next.js + TypeScript для сайта, Medusa.js для магазина, Postgres, сервер Hetzner. Одна кодовая база, версии для Украины и ЕС.

## Этапы создания сайта (предложены Денису 2026-10-08)
1. Вводные от Дениса. 2. Прототип конструктора на одном товаре (превью, мокап, файл для резки, проверка на станке). 3. Дизайн страниц. 4. Сборка магазина (каталог, корзина, WayForPay/monobank, Новая Почта, админка). 5. Наполнение и SEO. 6. Тест и запуск (переадресация со старого сайта, домен). 7. После запуска: отзывы, Prom/Rozetka, потом Польша и ЕС.

## Что известно о бизнесе
- ФОП 2-й группы в Украине, есть своё оборудование для изготовления трафаретов. Максимальный лист станка 1400 × 2000 мм; больше — составные трафареты из частей (Денис, 2026-10-08).
- Материалы и цены за м²: PET 0,5 мм прозрачный 2200 грн, полистирол 1 мм белый и чёрный 2300 грн, акрил 3 мм прозрачный 4000 грн.
- Сайт для Украины на двух языках: украинский и русский. Требование: профессиональный дизайн, читаемые шрифты, лучше конкурентов, SEO в топ.
- Текущий магазин, по данным его Google Ads: topperok.com.ua (топперы, подложки и коробки для тортов, трафареты, оргстекло). Реклама за год: [поисковые запросы](../research/google-ads/search-terms-2025-10_2026-10.csv).
