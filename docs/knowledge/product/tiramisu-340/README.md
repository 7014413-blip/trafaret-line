# Первый товар: трафарет «Обіцяю тебе…» для тирамісу

- Размер: Ø 340 мм под форму Ø 390 мм (по 2,5 см запаса до стенки).
- Текст: ОБІЦЯЮ / ТЕБЕ / зачёркнутое «бісити» / «любити» / сердце / дата. Покупатель меняет слова и дату.
- Перемычки 2,5 мм: середины О, Б, Я, Ю (и 0, 6 в дате), полоса по обе стороны линии зачёркивания, разрыв сердца сверху.
- Материалы Дениса (2026-10-08): полистирол 1 мм белый и чёрный, PET 0,5 мм прозрачный, акрил 3 мм прозрачный.
- Демо конструктора: https://claude.ai/artifact/VaHqaUaeiP7LykX1NDV9Hz (исходник constructor-demo-source.html; шрифты PT Serif Bold и Marck Script как приближение, opentype.js 1.3.4, перемычки считаются по внутренним контурам букв).
- Ждём: файлы шрифтов из макета, цены по материалам и диаметрам, подтверждение типа станка (вероятно лазер).
