## Главный вывод

**Конструктор есть только у одного из десяти: [Stencils Online](stencilsonline.md)** (текст, шрифты, клипарт, мгновенная цена, только США и только для промышленности и DIY без мокапов). У остальных буквы и цифры продают по одной (Stencil Giant, The Stencil Studio), а индивидуальные заказы идут через заявку и менеджера. [Stencil Monkey](stencilmonkey.md) продаёт индивидуальные трафареты как обычный товар (размер → загрузка картинки → оплата → макет на почту), но без превью: результат человек видит только после оплаты.

Наше отличие даже от Stencils Online: превью прямо на фото трафарета в нашем стиле, мокапы в интерьере в выбранном цвете, автоматические перемычки и продажи в Украину и ЕС на нескольких языках.

## Что собираем в наш сайт из лучшего у конкурентов
1. Навигация по стилю **и** по месту применения (стена, пол, мебель, фасад, ткань).
2. 6–10 фото в применении на товар, у нас генерируются мокапами в выбранном цвете.
3. Варианты «для чего (краска / штукатурка) → размер», таблица размеров в см.
4. Сопутствующие товары (краска, валик, кисть, скотч) со скидкой на комплект.
5. Отзывы с фото и ответами магазина, число отзывов в каталоге.
6. FAQ и инструкция в карточке, с разметкой для Google.
7. Посадочные страницы под частые запросы (буквы, цифры для дома, парковка, логотип), каждая открывает конструктор.
8. Мультивалютность и доставка с уже оплаченной пошлиной.
9. Обучение: видео, идеи, PDF за email, стартовые наборы.
10. Быстрая связь через Telegram / Viber / WhatsApp.
11. Точная дата доставки в карточке и −10 % за подписку (My Stencils).
12. Etsy как второй канал продаж и наборы из 2 трафаретов (Stencilit).
13. Ценовая лестница по размерам с дешёвым входом и авторские коллекции художников (iStencils).
14. Мгновенная цена в конструкторе, «быстрый расчёт текста», шрифты с фильтрами, выбор толщины с объяснением, B2B-раздел (Stencils Online).
15. Индивидуальный трафарет по картинке как обычный товар: цена по размеру, «дизайн и макет включены», оплата сразу, ускорение за доплату (Stencil Monkey).
16. Одинаковые сроки, гарантия и условия по всему сайту (у DFA и The Stencil Studio они противоречат друг другу).
