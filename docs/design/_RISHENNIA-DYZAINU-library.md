# Выбор дизайна: на чём основано решение

08.10.2026. Денис попросил выбрать вариант не «на вкус», а по данным: что лучше читается и лучше продаёт.

## Итог
**Берём вариант A («Лазерный рез») с доработками, из B берём только фото интерьера в карточках, вариант C — только для рекламных баннеров.**

## Правила, на которые опираемся
| Правило | Источник | Что это значит для нас |
| --- | --- | --- |
| Тёмный текст на светлом фоне читается быстрее и точнее, чем светлый на тёмном или текст на цветном | исследования NN/g о «dark mode» и контрасте (nngroup.com/articles/dark-mode) | фон страниц белый или очень светлый; жёлтый фон из C для текста не подходит |
| Контраст текста не ниже 4.5:1, крупного — 3:1 | WCAG 2.1, критерий 1.4.3 | тёмно-синий текст на белом даёт около 15:1; серые подписи не светлее #5a6b82 |
| Основной текст на телефоне от 16 px, интервал 1.4–1.6, строка до 70–75 знаков | рекомендации Baymard и WCAG 1.4.12 | основной текст 16 px на телефоне и 17 px на компьютере, межстрочный 1.5 |
| Кнопка покупки должна быть одного цвета, который больше нигде не используется, и заметно выделяться | исследования Baymard по карточке товара (baymard.com/research/product-page) | один акцентный синий только для «Купити», «Замовити», «У кошик»; остальные кнопки контурные |
| Цена и выбранные параметры видны рядом с кнопкой, без надбавок «+N грн» | Baymard, разбор topperok в `docs/research/ux-vybor-razmerov.md` | крупная цена, чипы размеров с ценой на каждом (уже в прототипе) |
| Фото товара на нейтральном фоне плюс фото в интерьере продают лучше, чем одно из них | Baymard (in-scale и lifestyle images) | в карточке: трафарет на белом, на стене, с рулеткой для масштаба |
| Шрифт без засечек с крупными строчными буквами лучше читается на экране телефона | общая практика интерфейсов (Material, Apple HIG) | для текста и кнопок — гротеск; рукописные и с засечками только в конструкторе и в редких заголовках |

## Почему не B и не C
- **B (Интерьер):** заголовочный шрифт с засечками красив, но хуже читается мелко и на телефоне, зелёный фон снижает контраст. Отлично подходит для фото и баннеров раздела «Стіни», а для всего магазина (маркировка, ОСББ, бизнес) — слишком «журнально».
- **C (Яркий):** жёлтый фон утомляет при чтении и выглядит дёшево для бизнеса и интерьера. Оставляем его для рекламы в Instagram и Facebook, где нужно выделиться в ленте.

## Что меняю в варианте A
1. **Шрифт основного текста:** вместо Golos Text берём **Inter** — один из самых проверенных шрифтов для интерфейсов, полная украинская кириллица (ї, є, ґ), бесплатный (OFL). Golos Text и PT Serif разработала московская ParaType, поэтому для украинского бренда я их убираю, в том числе из конструктора.
2. **Заголовки:** Unbounded оставляем только для H1–H2 и логотипа, коротко и крупно.
3. **Фон:** белый для карточек и каталога, светлый серо-голубой только для разделителей блоков.
4. **Акцент:** насыщенный синий только на кнопках покупки; цены — тёмно-синие жирные; скидки — зелёные.
5. **Пунктир линии реза** остаётся как фирменная деталь, но тонко и не на тексте.

## Что проверяем после запуска
A/B-тест цвета кнопки и порядка блоков карточки в Google Analytics: смотрим добавления в корзину и оформленные заказы, а не мнения.
